# Extensiones (Open VSX)

Prometheus Code conserva el ecosistema de extensiones de VS Code, pero con un
cambio importante: las extensiones se instalan desde **Open VSX**, el
registro abierto y comunitario — no desde el marketplace privado de VS Code.
Todo el ecosistema funciona igual: buscás, instalás, actualizás y administrás
desde el panel de extensiones.

## Instalar desde el panel

1. Abrí el panel de extensiones con `Ctrl+Shift+X`.
2. Buscá por nombre o por categoría (lenguajes, temas, linters, formatters…).
3. Clic en **Instalar** y la extensión queda activa en el momento.

Las extensiones de Open VSX son las mismas que conocés de la comunidad de VS
Code: compatibles con el editor, con licencias libres y publicadas por sus
autores.

> **Nota:** si buscás una extensión y no aparece, puede que solo esté
> publicada en el marketplace privado. En Open VSX se publican las versiones
> de código abierto, que es donde vive el ecosistema de Prometheus Code.

## El pack oficial

El editor tiene un pack oficial de extensiones publicado en Open VSX, que
podés buscar como:

```
Prometheus Code Extension Pack
```

Incluye la extensión **Prometheus AI** — el chat y los agentes automáticos —
y el resto del ecosistema del editor, todo con licencia libre. Si lo
instalás en otra instalación, tu entorno queda igual.
