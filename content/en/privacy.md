# Privacy policy

## No telemetry

Prometheus Code does not send usage data, errors or crash reports to Prometheus servers. Product telemetry is **disabled by default** on every installation.

## Data that stays on your device

- Chat history, persistent memory and settings are stored locally on your device.
- Local models run on your machine. The content of your conversations is not sent to any Prometheus or third-party server.
- The agent catalog and tools are loaded from local files.

## Remote models

If you choose to use a remote session, your messages are sent to the provider you select (OpenCode Free, OpenAI, Anthropic or Google Gemini), subject to that provider's privacy policy. Prometheus Code does not retain or process those messages.

## API keys

API keys are stored in the system secure storage (keyring) or, for OpenCode, in the local CLI authentication file. Prometheus Code does not transmit your keys outside your device, except to authenticate the call to the selected provider.

## License activation

License activation uses GitHub authentication and a hardware identifier derived from the device. This validates that the license belongs to a single device. We do not access your code, conversations or files.

## Website

The documentation site only stores a language preference. It does not use analytics, third-party cookies or tracking mechanisms.

## Contact

If you have questions about this policy, you can open an issue on [GitHub](https://github.com/andrexp31/prometheus-code-desktop/issues).
