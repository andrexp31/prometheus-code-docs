# Extensions (Open VSX)

Prometheus Code preserves the VS Code extension ecosystem, but with one
important change: extensions are installed from **Open VSX**, the open,
community-run registry — not from VS Code's private marketplace. The whole
ecosystem works the same: you search, install, update and manage extensions
from the extensions panel.

## Install from the panel

1. Open the extensions panel with `Ctrl+Shift+X`.
2. Search by name or by category (languages, themes, linters, formatters…).
3. Click **Install** and the extension is active immediately.

Open VSX extensions are the ones you know from the VS Code community:
compatible with the editor, under free licenses and published by their
authors.

> **Note:** if you search for an extension and it does not appear, it may
> only be published on the private marketplace. Open VSX hosts the
> open-source versions, which is where Prometheus Code's ecosystem lives.

## Built in, not as an extension

The Prometheus AI chat, the automatic agents and the local models are built
into the editor — you don't need to install any extension to use them. Open
VSX stays for the community extensions you want to add.
