# Download & Install

Prometheus Code is a fork of VS Code with its own identity. It is distributed
as a native Linux package (deb and rpm), and can also be run from source.

## Packages

| Platform | Format |
|---|---|
| Linux (Debian/Ubuntu) | `.deb` |
| Linux (Fedora/Arch) | `.rpm` |
| Windows | `.exe` |
| macOS | `.dmg` |

## From source

```bash
git clone https://github.com/andrexp31/prometheus-code-desktop.git
cd prometheus-code-desktop/Prometheus-Code
npm install
npm run compile-client
```
