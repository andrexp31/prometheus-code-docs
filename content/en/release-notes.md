# Release Notes

## 1.1.3 (current)

- **Native agent catalog in context**: Prometheus AI knows all 423 agents
  without needing a prior search. Ask "what agents do you have?" and it lists
  them with their categories.
- **Online documentation**: Help → Documentation opens the official
  Prometheus Code website with installation guides, models and Prometheus AI.
- **Prometheus Code website**: new public documentation with Spanish and
  English content.

## 1.0.0 — Initial release

- **Fork of VS Code (Code - OSS)** with its own identity: editing, debugging,
  built-in Git, terminal and extensions preserved from VS Code.
- **Local llama.cpp models**: integrated server with extensible context,
  quantized KV and CUDA acceleration for NVIDIA GPUs. Download models
  directly from Hugging Face.
- **Prometheus AI chat**: reasoning in your language with the local model,
  automatic agent selection and agent tools in the same conversation.
- **423 automatic agents**: specialists to plan, modify code, run commands
  and iterate until the task is done.
- **Embedded AI terminal**: commands live in the chat, with live output and
  exit codes.
- **Persistent memory and history**: the editor remembers conversations
  between sessions, and you can continue or restart them.
- **Live Preview**: its own pane with embedded Vite for your web projects.
- **Extensions from Open VSX** and bundled themes.
- **Full privacy**: no telemetry, no cloud — everything runs on your machine.
- **One-time payment**: lifetime license with no subscriptions and no locked
  features.
