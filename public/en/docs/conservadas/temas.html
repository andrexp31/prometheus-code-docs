Themes

Prometheus Code preserves VS Code's color and icon themes: dark, light or high-contrast editor, picked instantly from the theme selector included in the app.

Built-in theme selector

From the app's theme selector you can switch between dark and light themes:

Besides the default dark/light pair, the editor ships high-contrast variants and file icon themes, all ready to use without installing anything.

Changing the theme

Method Steps
Command Palette Ctrl+K Ctrl+T → Color Theme
Settings File → Preferences → Color Theme

The change is instant and applies to the whole UI: bars, panels, integrated terminal and editor.

More themes from Open VSX

If the built-in ones are not enough, there are thousands of themes published on Open VSX, the open extension registry: search "theme" in the extensions panel (Ctrl+Shift+X) and install them with one click. We cover this in Extensions (Open VSX).
